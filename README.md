# Bilgisayar Dünyası

5. sınıf öğrencileri için bilgisayar donanımını öğreten, akıllı tahtada oynanabilen bir web oyunu.

## Oyun modları

- **Bilgisayarı Topla:** Parçaları kasadaki doğru yuvalara sürükle, sonra bilgisayarı aç.
- **Eşleştir:** Parçanın resmini adıyla eşleştiren hafıza oyunu.
- **Bilgi Yarışması:** 10 soruluk test.
- **Giriş mi Çıkış mı?:** Birimleri doğru kutuya yerleştir.

## Nasıl çalıştırılır?

Kurulum ya da internet gerekmez. Klasörü indirip `index.html` dosyasına çift tıklamak yeterli.
Okulda kullanmak için klasörü USB belleğe kopyalayabilirsiniz.

Sadece HTML, CSS ve JavaScript kullanıldı. Bütün çizimler elle yapılmış SVG'dir.
Parça bilgileri `js/data.js` dosyasından değiştirilebilir.
